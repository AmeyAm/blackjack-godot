# Blackjack

A small blackjack game with a Godot UI and the original Python console version still included.

## Run it

Open this folder in Godot 4 and press play.

The Godot version starts with `$100`, lets you place a bet, then play the hand with:

- Deal
- Hit
- Stand
- Double

Dealer stands on 17. A push returns the bet and pays 10% interest, because that rule was funny enough to keep.

## Files

- `project.godot` - Godot project file
- `scenes/Main.tscn` - main scene
- `scripts/Main.gd` - blackjack UI and game logic
- `main.py` - original terminal version
